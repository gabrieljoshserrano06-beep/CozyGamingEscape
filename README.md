# Cozy Gaming Escape - Staycation Website

Modern luxury staycation web application for **Cozy Gaming Escape** located at **Trees Residences, Quezon City**.

## 🚀 Instant Deployment

This website is built with clean, zero-dependency HTML5, CSS3, and modern Vanilla JavaScript. It requires **no build step**, no `npm install`, and works out of the box.

### Option 1: GitHub Pages (Free Hosting)
1. Create a new repository on GitHub (e.g., `cozy-gaming-escape`).
2. Push or upload the contents of this folder.
3. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Branch**, select `main` (or `master`) and folder `/ (root)`.
   - Click **Save**.
4. Your site will be live at `https://<your-username>.github.io/cozy-gaming-escape/` in ~1 minute!

### Option 2: Netlify (Free Drag & Drop)
1. Go to [netlify.com](https://www.netlify.com/).
2. Log in and drag the entire `Cozy` folder onto the Netlify "Drop" zone.
3. Your site is instantly live with free SSL and custom domain support!

### Option 3: Vercel / Cloudflare Pages / cPanel
- Point the project root to this folder. It serves `index.html` automatically.
